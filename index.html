목표

구성
공격·강화·방어 아이템 8종을 구성하고, 최대 3개 보유·한 차례 1개 사용으로 선택의 범위를 정했습니다. 아이템 효과에 맞춘 캐릭터 동작과 컷씬의 방향도 구체화했습니다.

구성

문제와 개선 과정 ＋

01

다시 누른 평가가 두 번 저장되지 않도록

문제
중복 클릭과 재시도로 같은 평가가 여러 번 기록되거나, 늦게 도착한 조회 결과가 최신 화면을 덮을 수 있었습니다.
구현
평가 ID로 중복을 구분하고 카드 revision으로 오래된 상태를 확인합니다. 평가 로그·다음 일정·취소 정보를 트랜잭션으로 저장하고, 조회 결과의 세대 번호를 확인해 화면에 반영합니다.
확인
실패 지점을 주입해 롤백·재시도·중복 기록 방지 조건을 검사했습니다.

02

사진 인식의 오류가 단어장으로 이어지지 않게

문제
목록 표시가 영문에 섞이거나, 잘린 단어와 여러 줄 뜻이 잘못 연결되는 사진을 제시하고 개선을 요청했습니다.
구현
텍스트 좌표로 행·열을 재구성하고 모호한 결과는 검토 대상으로 남깁니다. 사용자가 후보를 수정·선택한 뒤 저장하도록 했습니다. 사진은 외부 OCR 서버로 보내지 않고 기기 안에서 처리합니다.

03

OCR 모델을 보존하면서 설치 파일 줄이기

문제
OCR 모델과 네이티브 런타임이 포함되면서 APK 크기가 커졌습니다.
구현
네이티브 라이브러리의 압축 패키징을 적용했습니다. 모델·런타임 바이트는 해시로 비교하고, 세 CPU 아키텍처가 유지되는지도 확인했습니다.
결과
APK가 204,426,852바이트에서 95,434,632바이트로 약 53.3% 줄었습니다. 설치 후 용량·메모리·인식 속도의 개선율을 뜻하지 않습니다.

개발·검증 자료 기준의 구현 설명입니다. 현재 스토어 공개 버전과 최신 개발 소스는 다를 수 있습니다.

문제와 개선 과정 ＋

01

닿아 보이는데 합쳐지지 않는 고양이

문제
흰 고양이 두 마리가 대각선으로 맞닿아 보여도 합쳐지지 않았습니다. 그림 외곽과 원형 물리 충돌 영역의 차이가 원인이었습니다.
구현
그림 외곽선의 추가 접촉 판정을 두고, 객체 ID 쌍으로 합성 후보를 관리해 이미 소비한 고양이와 중복 점수 반영을 제외했습니다.
확인
대각선·정지 상태 접촉, 떨어진 객체, 세 마리 동시 접촉 조건을 회귀 테스트로 남겼습니다.

02

가만히 있어야 할 때, 다시 떨어져야 할 때

문제
높게 쌓인 고양이가 미세하게 흔들리고 회전하는 현상을 플레이하며 확인했습니다.
구현
물리 엔진의 실제 꼭짓점으로 경계를 계산하고 바닥부터 지지 관계를 확인합니다. 안정된 객체는 쉬게 하고, 아래 지지가 없어지면 다시 깨어나 낙하하도록 보완했습니다.

03

효과음이 달라도 고양이 등장 순서는 같게

구현
고양이 생성 난수를 사운드·연출 난수와 분리했습니다. 시드의 공백과 유니코드를 정규화하고, 같은 입력으로 순서를 다시 생성합니다.
범위
같아지는 것은 등장 순서입니다. 떨어뜨리는 위치와 시점에 따라 점수와 물리 결과는 달라집니다.
