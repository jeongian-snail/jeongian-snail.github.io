# 정이안 포트폴리오

정이안의 웹·서비스 개발 포트폴리오입니다. 요주, 암기곡선 단어장, 냥냥드롭을 소개합니다.

## 실행

빌드나 패키지 설치가 필요 없는 HTML, CSS, JavaScript 정적 사이트입니다.

```sh
python -m http.server 8080
```

http://localhost:8080 에 접속합니다. GitHub Pages에서는 main 브랜치의 루트 경로를 배포 대상으로 지정합니다.

## 구성

- `index.html`: 소개, 프로젝트 내용, 학력, 연락 링크
- `style.css`: PC·모바일·인쇄 레이아웃
- `app.js`: 프로젝트 필터, 모바일 메뉴, 시드 실험, PDF 인쇄
- `favicon.svg`: 사이트 아이콘

## 동작

프로젝트를 웹·모바일로 필터링합니다. 다른 분류의 프로젝트에 대한 바로가기를 누르면 전체 목록으로 전환합니다. 상세 설명은 키보드로 열고 닫을 수 있습니다. 시드 실험은 냥냥드롭의 FNV-1a + Mulberry32 방식으로 1~4단계 등장 순서를 비교합니다. PDF로 저장을 누르면 모든 프로젝트와 상세 설명을 펼친 인쇄 화면을 엽니다.

외부 분석 스크립트, 쿠키, 서버 API, 문의 폼이 없습니다. 이메일 링크는 방문자의 메일 프로그램으로 연결됩니다.

## 내용 근거 및 표현 범위

- 요주: 공개 서비스 https://yoju.duckdns.org/ 의 로비·게임 규칙과 사용자 기획 기록. 확인되지 않은 서버 기술 스택·성능·테스트 통과 수는 적지 않았습니다.
- 암기곡선 단어장: 사용자 출시 확인과 `wordbook_portfolio_handoff.md`(2026-10-27)의 구현·검증 자료. 자료의 기존 명칭은 ‘망각곡선단어장’이며 사이트에는 사용자가 이번 요청에서 지정한 이름을 사용했습니다. 출시 버전 번호·다운로드 수·공개 상품 URL은 확인하지 못해 기재하지 않았습니다.
- APK 비교: 204,426,852 → 95,434,632바이트, 0.4.4 압축 패키징 비교. 모델·런타임 바이트와 지원 아키텍처 보존. 설치 후 용량이나 성능 개선율이 아닙니다.
- 냥냥드롭: 프로젝트 README와 `dist/seed.js`, 기존 포트폴리오의 재현·검증 기록. https://github.com/jeongian-snail/nyang_drop
- 개발·개선 작업의 AI 협업 사실을 명시합니다. 확인되지 않은 단독 개발·100% 기여 주장을 넣지 않았습니다.
